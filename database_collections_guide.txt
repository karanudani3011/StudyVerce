========================================================================
  COLLECTIONS OVERVIEW
========================================================================

1.  Collection:  users
    Purpose:     Stores all registered user accounts (students, tutors, admins)
    Fields:
      - _id              :  ObjectId  (auto-generated by MongoDB)
      - name             :  String    (Full name of the user)
      - email            :  String    (Unique, lowercase email)
      - password         :  String    (Bcrypt-hashed password, omitted for Google users)
      - googleId         :  String    (Firebase UID for Google Sign-In users)
      - username         :  String    (Auto-generated e.g. @alexjohnson412)
      - avatar           :  String    (Profile image URL — stored on Cloudinary)
      - bio              :  String    (Short bio/description)
      - role             :  String    (Enum: 'student', 'tutor', 'admin')
      - xp               :  Number    (Total experience points earned)
      - streak           :  Number    (Current daily study streak count)
      - dailyGoalMinutes :  Number    (User's daily study goal in minutes)
      - currentGoalMinutes: Number    (Minutes studied today)
      - savedPosts       :  [ObjectId] (Refs to Post documents)
      - enrolledCourses  :  [ObjectId] (Refs to Course documents)
      - createdAt        :  Date      (Auto-generated timestamp)
      - updatedAt        :  Date      (Auto-generated timestamp)

------------------------------------------------------------------------

2.  Collection:  courses
    Purpose:     Stores all educational courses on the platform
    Fields:
      - _id              :  ObjectId
      - title            :  String    (Course title)
      - category         :  String    (e.g. Physics, Mathematics, CS)
      - instructor       :  ObjectId  (Ref to users collection — tutor)
      - description      :  String    (Full course description)
      - lessonsCount     :  Number    (Total number of lessons)
      - thumbnail        :  String    (Course cover image URL — Cloudinary)
      - enrolledUsers    :  [ObjectId] (Refs to users collection)
      - tags             :  [String]  (Searchable tags)
      - createdAt        :  Date

------------------------------------------------------------------------

3.  Collection:  posts
    Purpose:     Stores educational social feed posts (images, notes, explanations)
    Fields:
      - _id              :  ObjectId
      - author           :  ObjectId  (Ref to users collection)
      - caption          :  String    (Post title/caption)
      - explanation      :  String    (Detailed educational content)
      - subject          :  String    (e.g. 'AI & Math', 'Physics')
      - mediaUrl         :  String    (Image/Video/PDF URL — Cloudinary)
      - mediaType        :  String    (Enum: 'image', 'video', 'pdf')
      - likes            :  [ObjectId] (Refs to users who liked)
      - comments         :  [{ user: ObjectId, text: String, createdAt: Date }]
      - createdAt        :  Date

------------------------------------------------------------------------

4.  Collection:  communities
    Purpose:     Stores study groups / learning communities
    Fields:
      - _id              :  ObjectId
      - name             :  String    (Community name)
      - description      :  String    (Community description)
      - members          :  [ObjectId] (Refs to users collection)
      - leader           :  ObjectId  (Ref to users — community creator)
      - avatar           :  String    (Community image URL — Cloudinary)
      - category         :  String    (e.g. 'Physics', 'CS', 'General')
      - createdAt        :  Date

------------------------------------------------------------------------

5.  Collection:  messages
    Purpose:     Stores direct messages between users & community chat messages
    Fields:
      - _id              :  ObjectId
      - sender           :  ObjectId  (Ref to users collection)
      - receiver         :  ObjectId  (Ref to users — null for community messages)
      - communityId      :  ObjectId  (Ref to communities — null for DMs)
      - text             :  String    (Message content)
      - read             :  Boolean   (Read receipt status)
      - createdAt        :  Date

------------------------------------------------------------------------

6.  Collection:  notifications
    Purpose:     Stores user notifications (likes, follows, achievements, etc.)
    Fields:
      - _id              :  ObjectId
      - recipient        :  ObjectId  (Ref to users — who receives the notification)
      - sender           :  ObjectId  (Ref to users — who triggered it)
      - type             :  String    (Enum: 'like', 'comment', 'follow', 'achievement', 'system')
      - message          :  String    (Notification text)
      - refId            :  ObjectId  (Reference to related post/course/community)
      - read             :  Boolean
      - createdAt        :  Date

------------------------------------------------------------------------

7.  Collection:  certificates
    Purpose:     Stores earned certificates for completed courses
    Fields:
      - _id              :  ObjectId
      - user             :  ObjectId  (Ref to users)
      - course           :  ObjectId  (Ref to courses)
      - issuedAt         :  Date
      - certificateUrl   :  String    (PDF/Image URL — Cloudinary)

========================================================================
  API ENDPOINTS SUMMARY
========================================================================

  Auth Routes (/api/auth):
    POST  /api/auth/register     — Register new user (name, email, password)
    POST  /api/auth/login        — Login user (email, password) → returns JWT
    POST  /api/auth/google       — Sync Google/Firebase user to MongoDB
    GET   /api/auth/me           — Get current user profile (requires JWT)

  User Routes (/api/users):
    GET   /api/users/dashboard   — Get user dashboard stats (requires JWT)
    PUT   /api/users/profile     — Update user profile (requires JWT)

  Upload Routes (/api/upload):
    POST  /api/upload            — Upload media to Cloudinary (requires JWT)

  Health Check:
    GET   /api/health            — Server status check
